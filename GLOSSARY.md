# Glossary

One word per thing. A term below has the same name in code, UI copy and docs. Add a term here before using it; never use the words in the last column.

| Term | Meaning | Never say |
|---|---|---|
| Sandbox | One configured pod: a workstation and its gatekeeper. | box, environment |
| Gate | What lets a sandbox's egress pass. It is open or locked. | firewall state, kill switch |
| Lease | The timed kernel entry that keeps the gate open. When it expires, the gate is locked. It lasts five seconds from when the last probe that was answered with an expected address was sent. At a gate that keeps a Hold, where its end cuts no connection, it lasts no longer than the time in which two more answers are due and three quarters of a second, from when the answer came: about two seconds with three probe URLs. | TTL entry, token |
| Hold | A second timed kernel entry, of a sandbox whose Setup asks for one: while it lasts, the connections the sandbox has are kept though the lease ran out for want of an answer. What they receive still arrives; what the sandbox sends on them waits at its Carrier, and leaves when the gate is open again. It makes no new one and asks no name. It lasts thirty seconds from when the last probe that was answered with an expected address was sent. What locks the gate for a reason it knows ends the Hold with the lease. | grace period, soft lock, keepalive, linger, pause |
| Heartbeat | The stream by which the app keeps a gatekeeper's lease alive, and tells it the Interface in use and this Mac's physical exit addresses. | keepalive, ping |
| Exit address | The public address the internet sees a sandbox at, by way of the Interface in use. | exit IP, egress IP |
| Physical exit address | A public address the internet sees this Mac at by way of a Physical Interface. An Allowed Interface may expect a physical exit address, which is what it exits at with no tunnel between; or any exit address but a physical one, for which the Interface in use is not counted among the Physical Interfaces. | own exit address, real IP, home IP, direct exit, local exit |
| Probe | A request that asks a public endpoint what address it was called from. The gatekeeper's read the sandbox's exit address; the Host Watchdog's, sent the same way from this Mac's physical Interfaces, read this Mac's physical exit addresses. | IP check, health check |
| Probe Source Ports | The ports the gatekeeper's probes are sent from, 61000 to 61999. The ruleset rejects what the sandbox sends from one of them, so the Carrier knows a probe's connection by its port, and sends it on whatever the gate says. | probe range, reserved ports |
| Round | One probe to each probe URL. The gatekeeper sends the first round of an Interface in use together, and spreads each one after it over two seconds, one probe URL after another at even distances; while a probe a second old has no answer, and none sent since has one, it asks each probe URL every second. The Host Watchdog sends a round together, every ten seconds by each of this Mac's physical Interfaces, or two seconds after the last while that interface has no answer it believes. | cycle, poll, tick, batch |
| Resolver | The one public DNS resolver a sandbox's name queries go to. | DNS server, nameserver |
| Stand-in address | An address of the range `198.18.0.0/15` that what an Interface leads to answers a name with, in place of the name's own: there it stands for the name, and it means nothing anywhere else. A sandbox connects to one only by an Allowed Interface whose Setup says that names are answered so there, and only while that is the Interface in use; where each leads is decided where the Interface leads, by the name it stands for. | fake IP, fake address, virtual IP, placeholder address |
| Host Condition | A fact about the Mac, other than its interfaces, that must hold for a sandbox's egress. | host gate, host environment check |
| Host Watchdog | What evaluates Host Conditions, and reads this Mac's physical exit addresses. | host monitor |
| Interface | A network interface of this Mac, known by its name alone: `en0`, `utun4`. The form offers the ones that are up under what the system calls each, and never asks for a name. | NIC, adapter, network card |
| Physical Interface | An Interface that is up with an IPv4 address, a hardware address and a default route through a router: `en0` on Wi-Fi or Ethernet. The name is for that test and for nothing else: a bridge has a hardware address and no router, and is not one. | own interface, real interface, hardware interface |
| Virtual Interface | An Interface that is not a Physical Interface: a tunnel, `utun4`. The tests have one that its owner makes, where a sandbox is seen at an exit address that no Physical Interface of this Mac leads to: an untracked fixture offers it to them, and reads the untracked file `instance_test`, where its owner wrote down what the fixture needs. | second interface, test instance |
| Allowed Interfaces | The Interfaces a sandbox may leave this Mac by, most preferred first. The Setup calls them what the sandbox leaves by. | interface list, fallback chain, routes |
| Interface in use | The one Allowed Interface a sandbox leaves by now: the first that is up with an address. There may be none. | active interface, current route |
| Carrier | The program the app runs for each running sandbox, which carries its traffic: it ends the sandbox's connections on this Mac and makes them again on sockets bound to the Interface in use. It dials only public addresses, and stand-in addresses by an Interface whose Setup says that names are answered with them, and listens on nothing. | proxy, relay, tunnel, NAT, gateway |
| Carrier Wall | The Seatbelt profile a Carrier runs under: connections out, and nothing else of this Mac. | sandbox profile, jail |
| TUN device | The one device of a sandbox's namespace besides loopback. Its packets are the Packet stream's. | bridge, veth, virtual NIC |
| Packet stream | A sandbox's packets as they cross between its TUN device and its Carrier, each behind its length. When it ends, the device is gone. | tunnel, pipe, channel |
| Capability Pack | A manifest that adds a tool to a sandbox. It runs in the workstation, never on the Mac. | plugin, productivity tool |
| Pack Catalog | The Capability Packs a sandbox can enable: the built-in ones, then the user's own, from the `packs` folder beside the saved sandboxes. | pack registry, pack store, pack library |
| Clock Policy | The timezone a sandbox's clock reads in: one of the tz database's, or that of its exit address. The clock itself is this Mac's, and nothing shifts it. | time policy, clock spoofing, clock mode |
| Gatekeeper | The container that owns the pod's network namespace and enforces the gate. Its own process carries no packet and listens on nothing; `tun`, beside it, moves the TUN device's. | firewall container, sidecar |
| Ruleset | The nftables rules a gatekeeper loads once into its namespace: everything they do not allow is rejected. | firewall, iptables |
| VM | The Linux VM of the Colima profile, in which every sandbox's containers run. | Docker host, Linux guest |
| Backstop | The second ruleset, in the VM, that limits what every container bridge reaches. No sandbox is on a bridge: it judges image builds. | VM firewall, outer firewall |
| Workstation | The container the agent works in. | main container |
| Shared Folder | A folder of this Mac, known by its name, that the workstations of the sandboxes given it mount at `/workspace/shared`, beside each one's Home. A sandbox is given one in its Setup, or none. Each has a row in the sidebar, under the sandboxes' Cards, which shows its page. | share, exchange folder, mount, volume, host folder, team folder |
| Home | A sandbox's own folder in the VM, which its workstation mounts at `/workspace`: the agent's home directory, where what you install and log in to stays. It is kept when the sandbox stops and deleted when the sandbox is destroyed. A clone has its own, empty. | workspace, volume, disk, storage, persistent folder |
| Link | The one stream by which what runs in a sandbox's workstation asks something of the app: the standard streams of the supervisor's `link`, run in the workstation and carried by the Docker API, so that nothing listens for it on this Mac and no port of the sandbox is published. Each ask is answered or refused; closing an ask's connection withdraws it. The app trusts nothing an ask says. | channel, bridge, socket, RPC, control stream |
| Host Tool | A program of this Mac that a sandbox's agent runs, by the tool `run` of the MCP server `host`: it runs under the Host Tool Wall, in the sandbox's Shared Folder, and its sandbox is given Host Tools in its Setup. The app starts it and relays what it prints. | host agent, host command, remote tool, Mac tool |
| Host Tool Wall | The Seatbelt profile every Host Tool runs under: it reads this Mac's public software, reads and writes its sandbox's Shared Folder and Host Tool Scratch, and has nothing else of this Mac: no file of yours, no network, no other program. A sandbox's Setup may add the GPU to it, and this Mac's name. | jail, cage, sandbox profile, whitelist |
| Host Tool Scratch | A sandbox's own folder on this Mac, outside every Shared Folder, where its Host Tools have their home directory, their temporary files and their caches. No workstation mounts it. It is deleted when the sandbox is destroyed. | private folder, tool home, cache folder, tools folder |
| GPU Shim | The small library loaded into a Host Tool that is given the GPU. It answers, in the tool's own process, two questions whose answer the system would fetch from a service the Wall refuses: where the user's cache folder is, which is in the Host Tool Scratch, and whether a piece of code is signed as it says, which is yes. | helper, forwarder, proxy, hook |
| Shell Startup File | The one line, in a file the app keeps beside the GPU Shim, that sets the loader's variable for the Shim again. This Mac's own programs drop that variable for whatever they start; bash and zsh read the file at every start that is not told to read none, so what they start has the Shim. `sh` reads no such file, and as the program of a request it is started as bash. | rc file, profile, dotfile, init script |
| Homebrew Wrapper | A link, named as a program of Homebrew's, to a script of the app's that sets the loader's variable for the GPU Shim and becomes that program. The wrappers' folder stands in a Host Tool's `PATH` before Homebrew's own, where the sandbox is given the GPU: a program of Homebrew's started by its name has the Shim, whatever started it. A script of Homebrew's has none. | shim script, launcher, stub, alias |
| Agent | A program and the model it drives. The app installs none and starts none: its user installs one in a workstation, and starts it there by typing its name in a Terminal Session. The app knows seven by their names. | harness, bot |
| Agent Executable | The name of the program an agent's own documentation starts it by: `claude`, `codex`, `grok`, `opencode`, `kimi`, `omp`, `agy`. It is what the app knows an agent by. No sandbox's config names one. | agent command, agent binary, launcher |
| Setup | A sandbox's configuration as its page shows it: its name, its network, its Shared Folder and the rest. It is the page of a sandbox that does not run, and stands in the Panes' place when the Header's Setup asks for it. Check, in the network, saves it and starts the sandbox with the Setup still shown, so that its gate says there whether the network is as required. Start starts the sandbox and shows its Panes. | wizard, onboarding, configuration, settings page |
| MCP Registry | The file in which an agent looks for the MCP servers it starts, in the shape its maker gave it: each known agent has its own. The supervisor writes the sandbox's servers into every one at each start, each as the same command, the supervisor's bridge with the server's name; an entry is the app's exactly when its command is that. What else a registry holds is its user's and the agent's, and stays as it is. | MCP config, server list, tool config |
| MCP Bridge | The supervisor's command `mcp-bridge <name>`, which every entry of an MCP Registry is: it starts the sandbox's MCP server of that name for the agent's client, and reports each message that crosses it. A pack's manifest names its server under `mcpBridge`. | MCP proxy, wrapper, shim |
| MCP Call | One message that crossed an MCP Bridge, as the bridge reported it: its time, its server, who sent it, its method and the start of what it carried. MCP Calls, in the Header, lists a sandbox's. | tool log, trace, request log |
| Supervisor | PID 1 of a workstation: it starts the packs' daemons and reports on them. | init, agent runner |
| Viewport Stream | Frames out of, and input into, one pack's display. | screen share, remote view |
| Browser Tab | One of the pages a pack's browser has open, as the browser lists them: its own title and its address. A viewport shows one at a time, and a strip over it, where the browser has more than one, chooses which. New Browser Tab, after the Address Bar, opens a blank one, and a link Command-clicked in a Pane opens in a new one; Close Browser Tab, beside it, closes the one shown while the browser has another. The window's own pages are never called so. | page, target, window |
| Address Bar | The field over a browser's viewport that holds the address of the Browser Tab shown, and sends that tab to the address typed into it. Back and Forward, before it, send that tab to the address before and after the one it is at in its own history. | URL bar, location bar, omnibox |
| Sandbox Terminal | The page of a running sandbox under its Header: its Panes, under the viewports of its packs where it has any. | console, shell panel |
| Pane | One of up to four places on a running sandbox's page, each of which shows one Terminal Session under a strip with its name, the agent that runs there and its controls. A sandbox starts with one; two stand side by side, and from three on they stand in two rows. A session that loses its Pane, by Close Pane or to a session dropped there, is Hidden if it is an Agent Session and ends if it is a plain shell's; the last Pane stays. | split, tab, side terminal, drawer |
| Terminal Session | One login shell on a terminal of the dashboard's, in a workstation, with whatever its user started in it. It has an ID in its workstation, under which the supervisor records it. | shell tab |
| Agent Session | A Terminal Session in which an agent runs: its user started one there. The workstation's supervisor says which, from the names of the session's processes: a program started under an Agent Executable, or a script of that name under node, bun, deno or python. It has its agent's glyph in the Header, and can be Hidden. When its agent quits in sight it is a plain shell's session again. | agent tab, chat, conversation |
| Hidden | Said of an Agent Session that no Pane shows: it goes on, behind its glyph in the Header, which shows it again by a click or when dragged onto a Pane. Only an Agent Session is Hidden: a plain shell that loses its Pane ends. | minimized, backgrounded, detached, parked |
| Dashboard | The app's window. | frontend, GUI |
| Header | The bar at the top of a page, which is the window's title bar there: a sandbox's name, the glyphs of its Agent Sessions, and the controls of what can be done with it, each a glyph. | toolbar, top bar, title bar |
| Glyph | A small picture drawn from a grid of characters in the source, as the icon is: what a sandbox's state looks like, what a control does, an agent's maker's mark. An Agent Session's glyph is its agent's, in the Header: muted while the session is Hidden, and worn with the Attention mark. A glyph says in a tooltip what it stands for. | icon, pictogram, sprite |
| Opening | What the window shows when the app starts: the cage of a zeolite's framework, turning, with the glyphs of the agents the app knows moving about inside it as living things do, drawn in characters on a grid as the icon is. It lasts under four seconds and gives way to the page; a click or a key ends it sooner, and whoever asked this Mac for less motion is shown none. | splash, splash screen, intro, loading screen, boot animation |
| Masthead | The picture at the top of the README: the cage of the Opening, turning without end, and beside it the app's name in italic letters made of characters, each of which trembles about its place as an atom does. It is drawn as the icon is, by a command, from the cage and the palette. | banner, logo, header image |
| Card | A sandbox's row in the sidebar: its name, which no other sandbox has, the glyph of its state, and the Attention mark while the sandbox needs you. With the pointer on it, it shows the sandbox's facts: its state, the agents that run in it, why it needs you, its gate and its workstation. The Cards of the sandboxes that need you come first. | tile, entry |
| Raised hand | What an agent does when it cannot go on without its user: it calls the tool `raise_hand` of the MCP server `sandbox`, which every sandbox has. The server finds the Terminal Session its agent runs in, and the sandbox's Link carries the hand to the app, which marks that session. It carries no words; the agent says what it needs in its session. | help request, escalation, ping |
| Attention mark | The glyph of a raised hand, worn by a Card while its sandbox needs you, and by an Agent Session's glyph, at its top right, while that session does: it raised its hand, rang or sent a notification while it was not in sight, or its agent ended while it was Hidden. A Card wears it too while a session ended with its sandbox not shown, and while the gate is locked. The app learns of a ring and a notification from the terminal, and reads nothing a session prints. | notification dot, unread badge, alert |
| Palette | The app's colors, one set for the window, the Sandbox Terminal and the icon. | color scheme, skin |
| TUN capture | The tests' packet capture on a sandbox's TUN device, which says what the sandbox actually sent. | oracle, sniffer |
| Translator | The tests' program that answers the Gemini API on a workstation's loopback by asking OpenRouter: Antigravity speaks that API alone, and OpenRouter does not. The test that gives every known agent a job starts it in its sandbox's workstation, beside Antigravity; the app has none and starts none. | proxy, gateway, relay, shim, adapter |

"Plugin" is reserved for MyGo's own plugins (`plugins/terminal`, `plugins/automation`), which is why a Capability Pack is never called one.
